**Java Security Animated** is an open-source Swing application that walks through core Java security concepts and shows how those ideas show up in frameworks such as Spring, Java EE, and OSGi.

The project lives on GitHub:

[https://github.com/martinfmi/java_security_animated](https://github.com/martinfmi/java_security_animated)

## Why it exists

The Java platform has a rich security model — permissions, policy files, class loaders, and framework-specific authorization layers — but it is often taught as a pile of APIs rather than a living system. The animated approach makes those interactions easier to see.

The naming and teaching style were inspired by Victor Grazi’s [Java Concurrent Animated](https://github.com/vgrazi/java-concurrent-animated), used with permission.
