<h2>30 years Java, 10 years jPrime</h2>
<p>Another year, another great Java communty conference happened in Bulgaria among the big shift happening in the tech industry over the AI hype. But Java is not only AI friend but with all the great frameworks in Java ecosystem like Apache Spark and Elasticsearch including new players like LangChain4j and Spring AI and libraries like DeepLearning4j and Weka the platform is more than ever ready to adopt AI awareness in every spectrum.&nbsp;</p>
<p>So apart from AI some of the main highlights from this year's jPrime include:</p>
<ul>
<li>modern approaches for teaching Java to beginners;</li>
<li>the new stream gatherers;</li>
<li>Java class file API;</li>
<li>messaging beyond Kafka;</li>
<li>Spring cloud AWS;</li>
<li>topics on security and platform engineering;</li>
<li>distributed tracing with OpenTelemetry;</li>
<li>again AI and AI :- ))</li>
</ul>
<p>All of this will not be possible without a number of sponsoring and participating companies from the Bulgarian Java ecosystem and close to 1200 attendees showing keen and active interest to sharpen their knowledge further apart from all the fun and networking possibilities the conferences provided again.</p>
