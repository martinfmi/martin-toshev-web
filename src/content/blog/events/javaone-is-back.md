<h2>The conference …</h2>
<p>JavaOne is back! Yes, after a few years of uncertainty the conference is back and it was a blast. It managed to gather the Java community from all around the globe: from Oracle architects and advocates to Java community leaders and enthusiasts. There was also presence of companies from the Java ecosystem including also Microsoft that is doing more and more to support and integrate Java in their services, like Azure.</p>
<p>Although the conference was smaller in size (yes it was not in Moscone this time where there was another big game development conference that took at the same time), it was still at a very nice location at Oracle’s premises in RedWood Shores and close to San Francisco:</p>
<p><img src="/images/legacy/events/javaone-is-back/IMG_20250318_161354.jpg" width="500" height="375"></p>
<p><img src="/images/legacy/events/javaone-is-back/IMG_20250321_195422.jpg" width="500" height="374"></p>
<p>The team at Oracle has put a great effort to make the conference very eventful and convenient for networking among attendees of any backgrounds. To assert that there was a Java pavilion where you can meet and talk to the architects, exchange and propose ideas. There were several events around the main conference like the Happy Hour and Attendee afterparty where you can do the same and at the same time have some fun and relax from all the collaboration during the conference days.</p>
<p><img src="/images/legacy/events/javaone-is-back/IMG_20250318_081012.jpg" width="500" height="666"></p>
<p><img src="/images/legacy/events/javaone-is-back/IMG_20250318_081053.jpg" width="500" height="666"></p>
<p><img src="/images/legacy/events/javaone-is-back/IMG_20250318_082931.jpg" width="500" height="375"></p>
<p>For me personally JavaOne was also a great way to reconnect with friends from the global Java community I’ve met at various events throughout the years primarily when I was delivering a session. These are people like Jonathan Vila from the Barcelona JUG,&nbsp;Andrzej Grzesik&nbsp; from the Polish Java community,&nbsp;Andrii Rodionov from the Ukraine Java user group, Chandra Guntur from the New York Java community, Bruno Souza from the Brazilian Java community, all of them Java pioneers and also conference organizers. There were also Java leaders from the various Java user groups in the United States.</p>
<p>Some highlights from the conference include:</p>
<ul>
<li>lambdas and structured concurrency;<br><br></li>
<li>project Helidon and how it averages lambdas for significant performance gains;<br><br></li>
<li>project Leyden and AOT improvements for fast startup time;<br><br></li>
<li>GraalVM and improvements around it;<br><br></li>
<li>Function and memory access as per project Panama;<br><br></li>
<li>AI toolbox for Java developers, LangChain4j and Spring AI in particular;<br><br></li>
<li>improvements on collections and streams;<br><br></li>
<li>security improvements in the JDK (including the removal of Security Manager and new cryptographic algorithm);<br><br></li>
<li>JavaFX;<br><br></li>
<li>further improvements and new things coming in future releases.</li>
</ul>
<p><br>And one more thing I would like to highlight separately as a person who has conducted a Java community academy and mentoring of junior developers that constantly ask me where they can learn Java: the new <a href="https://martin-toshev.com/learn.java">learn.java</a> platform announced at JavaOne.</p>
