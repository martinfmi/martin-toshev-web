Security has been a recurring theme in my consulting work, conference talks, and open-source teaching materials — especially around the Java platform security model and how frameworks implement it in practice.

## Consulting

I help teams reason about application and platform security on the JVM: authentication and authorization boundaries, secure modular deployments, dependency and supply-chain hygiene, and practical hardening for enterprise systems.

## Java Security Animated

[Java Security Animated](https://github.com/martinfmi/java_security_animated) is a Swing application that demonstrates core Java security concepts along with the security models used by frameworks such as Spring, Java EE, and OSGi.

The idea builds on [Java Concurrent Animated](https://github.com/vgrazi/java-concurrent-animated) by Victor Grazi (used with permission for naming and approach).

## Talks & writing

Security-related sessions I have delivered over the years include:

- Java Security Animated
- Java Security Architecture / Security Architecture of the Java Platform
