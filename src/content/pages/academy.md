Academy is the longer-form learning track — structured curricula and materials for developers who want deeper practice than a single workshop.

## Java Developer Training

[java_developer_training](https://github.com/martinfmi/java_developer_training) is a full **6-month Java developer training** curriculum covering fundamentals through practical application development.

It is openly available on GitHub and has been used by individuals and teams looking for a guided path into professional Java development.

## Related learning paths

Shorter, on-demand workshops are listed under [Trainings](/trainings/), including:

- Developing OSGi applications
- Developing Apache Spark applications
- Java security workshops and related deep-dives

## How to use it

1. Start with the public training repository on GitHub
2. Combine it with targeted workshops from the Trainings page
3. Follow related articles in [Blog](/blog/) for architecture, tools, and security topics

If you are interested in a private academy cohort or a customized learning path for your team, reach out via [LinkedIn](https://www.linkedin.com/in/martin-toshev-07046127/).
